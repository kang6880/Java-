# 注册接口对接说明（前端 fanren-login-vue）

后端：springBootTest（Spring Boot 3.4.5），默认端口 **8081**，数据库 MySQL 8 `fanren_login.t_user`。

---

## 一、接口清单

### 注册

```
POST http://localhost:8081/api/user/register
Content-Type: application/json
```

路径有 4 个别名，任选其一均可：

| 路径 | 说明 |
|---|---|
| `/api/user/register` | 推荐 |
| `/api/auth/register` | 备选 |
| `/api/register` | 备选 |
| `/user/register` | 兼容旧写法 |

### 请求字段

| 字段 | 必填 | 约束 | 兼容的其他命名 |
|---|---|---|---|
| username | 是 | 3~50 位，字母/数字/下划线/中文，唯一 | userName、user_name、account、loginName、name |
| password | 是 | 6~32 位 | pwd、userPassword |
| confirmPassword | 否 | 与 password 一致 | repassword、password2 |
| email | 否 | 合法邮箱格式，唯一 | mail |
| phone | 否 | 11 位手机号，唯一 | mobile、tel、phoneNumber |
| nickname | 否 | 默认取 username | nickName、realName |

字段名**忽略大小写**，前端用驼峰还是下划线都能接住。

### 响应结构

成功：

```json
{
  "code": 200,
  "success": true,
  "msg": "注册成功",
  "data": { "id": 1, "username": "luffy", "nickname": "草帽小子", "createTime": "2026-09-21T09:53:32" }
}
```

失败：

```json
{ "code": 409, "success": false, "msg": "用户名已被注册", "data": null }
```

| code | 含义 | 前端处理建议 |
|---|---|---|
| 200 | 成功 | 提示并跳转登录 |
| 400 | 参数错误 | 直接展示 `msg` |
| 409 | 用户名/邮箱/手机号已存在 | 聚焦到对应输入框 |
| 500 | 服务端异常 | 提示稍后重试 |

### 健康检查

```
GET http://localhost:8081/api/ping
→ {"code":200,"msg":"服务正常","data":{"status":"UP"}}
```

## 二、axios 调用示例

```js
import axios from 'axios'

const api = axios.create({
  baseURL: 'http://localhost:8081',
  timeout: 10000,
  headers: { 'Content-Type': 'application/json' }
})

export async function register(form) {
  const { data } = await api.post('/api/user/register', {
    username: form.username,
    password: form.password,
    confirmPassword: form.confirmPassword,
    email: form.email,
    phone: form.phone
  })
  if (data.code !== 200) {
    throw new Error(data.msg)
  }
  return data.data
}
```

### 用 Vite 代理（可选，彻底避开跨域）

`vite.config.js`：

```js
export default {
  server: {
    proxy: {
      '/api': { target: 'http://localhost:8081', changeOrigin: true }
    }
  }
}
```

配好后前端直接写 `/api/user/register` 即可，不用带域名。

## 三、Vue 3 组件片段

```vue
<script setup>
import { ref } from 'vue'
import { register } from '@/api/user'

const form = ref({ username: '', password: '', confirmPassword: '', email: '' })
const loading = ref(false)
const errorMsg = ref('')

async function onSubmit() {
  errorMsg.value = ''
  loading.value = true
  try {
    const user = await register(form.value)
    alert(`注册成功，ID：${user.id}`)
    // router.push('/login')
  } catch (e) {
    errorMsg.value = e.message
  } finally {
    loading.value = false
  }
}
</script>

<template>
  <form @submit.prevent="onSubmit">
    <input v-model="form.username" placeholder="用户名" />
    <input v-model="form.password" type="password" placeholder="密码" />
    <input v-model="form.confirmPassword" type="password" placeholder="确认密码" />
    <input v-model="form.email" placeholder="邮箱（选填）" />
    <button :disabled="loading">{{ loading ? '提交中…' : '注册' }}</button>
    <p v-if="errorMsg" style="color:#c0392b">{{ errorMsg }}</p>
  </form>
</template>
```

## 四、后端已处理的事（前端不用管）

- **跨域**：已全局开放 CORS（含 `file://` 直接打开页面的情况）
- **密码加密**：BCrypt 落库，返回体里不含密码
- **查重**：用户名唯一约束 + 查重判断，重复返回 409
- **异常处理**：任何异常都返回统一 JSON，不会吐 Spring 默认错误页

---

## 五、常见坑

1. **端口**：后端是 **8081**（dev 环境配置），别写成 8080
2. **Content-Type**：axios 默认就是 `application/json`，别手动改成表单，否则走另一套解析
3. **密码明文**：后端会自己 BCrypt 加密，前端正常传明文即可（走 HTTPS 另说）
4. **中文用户名**：支持，但建议前端也限制 3~50 位，避免后端往返
